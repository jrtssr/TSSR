**OSI** : modèle en 7 couches qui décrit le trajet d'une donnée sur un réseau, du câble jusqu'à l'application. Comme les étapes d'un colis, de l'emballage à la livraison.

**TCP/IP** : le modèle qu'Internet utilise vraiment, en 4 couches. TCP s'assure que tout arrive, UDP envoie vite sans vérifier.

**BIOS/UEFI** : le premier programme qui se lance quand tu allumes le PC. Il vérifie le matériel puis démarre Windows. BIOS = l'ancien, UEFI = le moderne.

**ISO/image** : ISO = un DVD copié dans un seul fichier (ex : l'installateur de Windows). Image = une photo complète d'un système, qu'on peut recopier sur d'autres PC.

**WDS/déploiement** : WDS = outil de Windows Server qui installe Windows sur plein de PC par le réseau. Déploiement = installer la même chose partout, en une fois.

**Bridge/NAT/Host-only** : les 3 façons de brancher une machine virtuelle. Bridge = elle devient un vrai PC du réseau. NAT = elle passe par la connexion de ton PC. Host-only = elle ne parle qu'à ton PC, pas d'Internet.

**Octets/bits** : le bit est la plus petite unité, un 0 ou un 1. L'octet, c'est 8 bits.

**PXE** : permet de démarrer un PC depuis le réseau, sans clé USB ni disque.

**DHCP** : le distributeur d'adresses IP. Chaque appareil qui se connecte en reçoit une automatiquement.

**MBR/GPT** : deux façons d'organiser les partitions d'un disque. MBR = ancien, limité à 2 To et 4 partitions. GPT = récent, presque sans limite.

**Rufus/Ventoy** : logiciels pour créer une clé USB qui démarre. Rufus = une seule ISO par clé. Ventoy = plusieurs ISO sur la même clé, tu choisis au démarrage.

**Partition** : une zone d'un disque, comme une part dans un gâteau.

**NTFS** : la façon dont Windows range les fichiers sur un disque.

**Signature** : un sceau numérique qui prouve qu'un fichier est officiel et n'a pas été modifié.

**VMware** : logiciel qui crée des PC virtuels dans ton PC.

**Windows Server** : Windows conçu pour les serveurs. Il gère les comptes, les fichiers et le réseau d'une entreprise.

**DNS** : l'annuaire d'Internet. Il traduit un nom (google.fr) en adresse IP.

**IP/MAC** : l'IP est l'adresse d'un appareil sur le réseau, elle peut changer. La MAC est le numéro de série de sa carte réseau, il ne change pas.

**IEEE 802.3/802.11** : 802.3 = la norme du réseau par câble (Ethernet). 802.11 = celle du Wi-Fi.

**Hyperviseur type 1/2** : le programme qui fait tourner les machines virtuelles. Type 1 = installé directement sur la machine, sans Windows dessous (ESXi, Hyper-V). Type 2 = installé comme un logiciel dans Windows (VMware Workstation).
